# MultiHD Launcher — Help

**Questa FSE · Quartus Prime · Gowin EDA — one-click SystemVerilog launcher for VS Code**

MultiHD Launcher (formerly *Questa Launcher*) turns a folder of SystemVerilog files into a
complete simulation / synthesis project: it generates the tool project files, applies your
Questa compile order and per-file exclusions, injects the license environment, and launches
the chosen EDA tool from a dark cyber launcher panel.

---

## Quick start

1. Open any `.sv` file from your project folder.
2. Run **🚀 Open MultiHD Launcher** (or click a title-bar button) to open the launcher panel.
3. First time only: **⚙ Configuration** → set the `vsim` path and license file.
4. Tick **`⬡  Questa / Modelsim`**, **`◈  Quartus Prime`** and/or **`◆  Gowin EDA`**.
5. Click **`▶   LAUNCH`** and watch the log; output also appears in **Output → MultiHD Launcher**.

## Questa FSE — launch modes

| Mode | `add wave -r /*` | `quit -f` |
|---|---|---|
| CLI | omitted | appended |
| GUI | included | omitted (keeps the window open) |
| Show WaveForm | writes a separate `wave.do` | — |

Generated `run.do`:

```tcl
# Questa run script — generated by MultiHD Launcher
# <ISO timestamp>

quietly vlib work
vlog -work work design.sv counter.sv counter_tb.sv
vopt +acc work.counter_tb -o counter_tb_opt
vsim counter_tb_opt
add wave -r /*
run -all
```

With project libraries linked, `run.do` also compiles each dependency into its shared work
database and passes `-L` flags to `vlog`, `vopt` and `vsim`. An uncompiled dependency logs
`⚠ Library "<name>" not compiled — open 📦 LIBRARIES.`.

## Generated files

### Quartus Prime

| File | Purpose |
|---|---|
| `<project>.qpf` | Quartus Prime project file |
| `<project>.qsf` | Family, device, top-level entity, file list, SDC reference |
| `<project>.sdc` | Timing template — written only if missing, hand edits preserved |
| `output_files/` | Output directory pre-created |

### Gowin EDA

| File | Purpose |
|---|---|
| `<project>.gprj` | Gowin IDE project XML (device, file list, top module) |
| `<project>.cst` | Pin constraints — `IO_LOC` template with auto-detected ports |
| `<project>.f` | File list for `vlog` / `iverilog -f` flows |
| `impl/pnr/` | Implementation output directory pre-created |

Replace the placeholder `XX` pin numbers in the `.cst` with your board's LOC values.
Cancelling the CST editor writes no Gowin files.

## Configuration — 7 fields

| Field | Setting / env var | Example |
|---|---|---|
| vsim binary | `multihdLauncher.vsimPath` | `~/altera/25.1std/questa_fse/linux_x86_64/vsim` |
| License file | `multihdLauncher.licenseFile` (`LM_LICENSE_FILE`) | `~/.licenses/questa_license.dat` |
| Default folder | `multihdLauncher.defaultFolder` | `~/projects/` |
| Quartus binary | `multihdLauncher.quartusPath` | `/usr/bin/quartus` |
| Gowin IDE binary | `multihdLauncher.gowinPath` | `/opt/gowin/IDE/bin/gw_ide` |
| SALT_LICENSE_SERVER | `multihdLauncher.saltLicenseServer` | license path or `port@host` |
| MTI_VCO_MODE | `multihdLauncher.mtiVcoMode` | `64` |

Each field has a `Browse` button. The dialog (`MultiHD Launcher — Configuration`, heading
`⚙   CONFIGURATION`) shows a live banner: `⚠  LICENSE FILE NOT SET  —  Questa will not start
without a valid license.` / `⚠  LICENSE FILE NOT FOUND  at:  <path>` /
`✓  License file found — Questa should start correctly.` Invalid fields are highlighted red;
`✓   SAVE` persists the settings.

Additional settings: `multihdLauncher.questaBin`, `multihdLauncher.licenseServer`,
`multihdLauncher.alteraLicenseFile`, `multihdLauncher.extraVlogArgs`,
`multihdLauncher.autoOpenGui`. Legacy `questaLauncher.*` values are read as fallbacks.

## License guard

Questa will not launch without a valid license. When the license file is empty or missing:

- the launcher badge shows `⚠ LICENSE NOT SET — configure before launching Questa!`;
- the launch button reads `⚠   LAUNCH  (Questa: no license!)`;
- the log shows `✗ [Questa] BLOCKED: License file not configured or not found!` and offers
  to open **⚙ Configuration**.

Quartus Prime and Gowin EDA launches are not affected by the license guard.

## Library manager

| Item | Location |
|---|---|
| Registry | `~/.questa_libs/registry.json` |
| Compiled libraries | `~/.questa_libs/work/<name>` |
| Project dependencies | `<project>/questa_libs.json` |

`＋  ADD LIBRARY` registers a folder containing at least one `.sv`; `⚡  COMPILE` runs
`vlib`/`vlog` in the shared work database; ticking a library in *THIS PROJECT'S DEPENDENCIES*
adds it to `questa_libs.json` and links it into `run.do` with `-L` flags; `✓   DONE` saves.

## conf.svconf

A `conf.svconf` in the project folder controls compilation:

```
compile @(all)          # all | list | N

@tb (counter16_tb.sv)   # explicit testbench
@tb priority list:      # testbench order (compiled last)
  - counter16_tb.sv
@priority list encoder: # RTL order (compiled first)
  - byte_register.sv
  - counter16.sv
@topmodule: counter16_tb

# @vsimargs: -voptargs=+acc
# @vlogargs: -sv
# @work: work
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| `vsim: No such file` | Set `multihdLauncher.vsimPath` in **⚙ Configuration** |
| Launch blocked / license badge red | Point `licenseFile` at an existing `.dat` file |
| No `.wlf` when showing waveform | Run **🖥 Run GUI** or **▶ Run CLI** first |
| Quartus / Gowin files written but tool not opened | Set `quartusPath` / `gowinPath` or add the tool to `PATH` |
| Files missing from compilation | Check **✕ Exclude Files** and `conf.svconf` |
| Library warning in `run.do` | Open **📦 Library Manager** and compile the library |
